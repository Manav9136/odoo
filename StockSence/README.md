# StockSense – Inventory Management System

StockSense is a web-based inventory management system designed to simplify
warehouse and stock operations.

The system provides a centralized interface for managing inventory,
receipts, deliveries, internal stock transfers, stock adjustments,
operations, and user authentication.

---

## 🚀 Features

- 🔐 User Authentication
  - User registration
  - Email/password login
  - Password reset
  - Logout

- 📊 Dashboard
  - Inventory overview
  - Total products in stock
  - Low/out-of-stock products
  - Pending receipts
  - Pending deliveries
  - Recent stock movements
  - Available stock

- ⚙️ Operations Management
  - Receipts
  - Delivery Orders
  - Internal Transfers
  - Stock Adjustments
  - Create new operations
  - Operation status tracking

- 📦 Inventory Management
  - Product stock information
  - Warehouse information
  - Stock quantity tracking
  - Stock movement tracking

- 👤 User Management
  - User profile
  - Login/logout
  - Secure authentication

- ☁️ Firebase Backend
  - Firebase Authentication
  - Cloud Firestore
  - Firebase Hosting
